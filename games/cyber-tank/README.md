# Cyber Tank: Ricochet Arena 🎯

A fast-paced 3D arcade top-down action shooter built with the **Ursina Engine**.

Control your tank, calculate bouncing bullet trajectories off walls using predictive laser sights, clear enemy waves, and collect powerful combat pickups!

---

## 🎮 Features
- **Tactical Ricochet Physics:** Bullets bounce off walls to strike targets around corners.
- **Predictive Trajectory Preview:** Dynamic laser line visualizes both the direct shot and initial bounce path.
- **Enemy Variety:** Agile Drones, Lock-on Sentry Turrets, and Heavy Goliath Boss Tanks.
- **Dynamic Arena:** Destructible crates dropping loot, explosive barrels with chain reactions.
- **5 Combat Power-Ups:** Tri-Shot, Hyper-Bounce, Rapid-Fire, Plasma Shield, Repair Core.
- **Zero External Audio Needed:** Pure Python procedural sound generation fallback.

---

## 🕹️ Controls

| Control | Action |
|---------|--------|
| **W, A, S, D** / Arrows | Move Tank |
| **Mouse Move** | Aim Turret & Predictive Sight |
| **Left Click** / **Space** | Fire Ricochet Shell |
| **Right Click** / **Shift** | Thruster Dash (Invulnerability frames) |
| **R** | Restart Match |
| **ESC** | Pause / Options / Quit |

---

## 🚀 How to Run

```bash
# 1. Ensure Ursina is installed
pip install ursina

# 2. Run from this directory
python main.py
```
