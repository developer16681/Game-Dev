# Crystal Arena 💎

A 3D first-person sci-fi arena shooter built with **Ursina** and **NumPy**.

Battle hovering Gloom Orbs, collect glowing golden crystals to replenish health and score, and survive inside an atmospheric neon-lit colosseum.

---

## 🎮 Features
- **Mathematical Audio Synthesis:** Sound effects and chiptune synth music generated on the fly via NumPy formulas.
- **Dynamic Arena Lighting:** Real-time directional sun shadows, colored fog, and neon aesthetic pillars.
- **Fast-Paced FPS Combat:** Fluid movement, projectile physics, and responsive reticle feedback.

---

## 🕹️ Controls

| Key | Action |
|-----|--------|
| **W, A, S, D** | Move |
| **Space** | Jump |
| **Mouse Look** | Aim |
| **Left Click** | Shoot Laser |
| **R** | Restart Round |
| **ESC** | Quit |

---

## 🚀 How to Run

```bash
# 1. Install Dependencies
pip install ursina numpy

# 2. Run the game
python main.py
```
