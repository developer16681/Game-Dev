# Tic-Tac-Toe Deluxe ⭕❌

A polished, animated Tic-Tac-Toe game built with **Pygame**.

Play against a friend locally or challenge an unbeatable Minimax algorithm AI!

---

## 🎮 Features
- **Smart AI Modes:** Unbeatable Minimax AI mode or casual Easy AI.
- **2-Player Local Mode:** Pass-and-play matches with win counters.
- **Visual Polish:** Animated strokes, victory line glows, floating background particles, and celebratory confetti.
- **Synthesized Audio:** Built-in procedural 8-bit chiptune BGM and UI sound effects.

---

## 🕹️ Controls

| Control | Action |
|---------|--------|
| **Mouse Left Click** | Place Mark / Press Menu Buttons |
| **R** | Restart Round |
| **M** | Toggle Background Music |
| **S** | Toggle Sound Effects |
| **ESC** | Back to Menu / Quit |

---

## 🚀 How to Run

```bash
# 1. Install Pygame
pip install pygame

# 2. Run the game
python main.py
```
