# Open World RPG ⚔️

An open-world survival, exploration, and combat RPG built with the **Ursina Engine**.

Explore a procedural world, harvest resources, craft weapons and gear, combat hostile creatures, and save your progress!

---

## 🎮 Features
- **Exploration & Gathering:** Roam an expansive terrain, mine ores, chop wood, and gather ingredients.
- **Crafting System:** Interactive recipe crafting menu with item requirements.
- **Combat Mechanics:** Sword melee strikes, bow projectile shooting, and enemy aggro AI.
- **Inventory & Hotbar:** 8-slot hotbar with scroll wheel selection and item usage.
- **Save & Load:** Complete state persistence to JSON (`F5` quicksave / `F9` quickload).

---

## 🕹️ Controls

| Key | Action |
|-----|--------|
| **W, A, S, D** | Move Character |
| **Shift** | Sprint |
| **Space** | Jump |
| **E** | Interact / Harvest |
| **Tab** | Open / Close Crafting Menu |
| **F** | Use Selected Item |
| **Left Click** | Attack (Melee / Shoot Bow) |
| **1 – 8** / Scroll Wheel | Select Hotbar Slot |
| **F5** | Save Game |
| **F9** | Load Game |
| **ESC** | Pause / Quit |

---

## 🚀 How to Run

```bash
# 1. Install Ursina
pip install ursina

# 2. Run the game
python main.py
```
