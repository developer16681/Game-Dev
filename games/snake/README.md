# Neon Snake 🐍

A modern, polished 2D arcade Snake game built with **Pygame**.

Featuring smooth movement animations, neon glow effects, particle trails, and procedural chiptune sound synthesis.

---

## 🎮 Features
- **Modern Neon Visuals:** Glowing grid, vibrant snake segments, and floating particle fruit effects.
- **Synthesized Audio:** Built-in procedural sound effects and retro background chiptune.
- **Score Tracking:** Live score, high score persistence, and game speed ramp.

---

## 🕹️ Controls

| Key | Action |
|-----|--------|
| **Arrow Keys** / **W, A, S, D** | Steer Snake |
| **Space** / **Enter** | Start / Restart Round |
| **P** | Pause / Resume |
| **M** | Toggle Music |
| **N** | Toggle Sound Effects |
| **ESC** | Quit |

---

## 🚀 How to Run

```bash
# 1. Install Pygame
pip install pygame

# 2. Run the game
python main.py
```
