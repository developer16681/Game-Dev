# Zombie Survival FPS 🧟

A 3D first-person zombie wave survival game built with the **Ursina Engine**.

Navigate an obstacle arena, manage ammunition, defend yourself from chasing zombie entities, and aim for a high kill count.

---

## 🎮 Features
- **Chasing Enemy AI:** Zombies locate and swarm the player continuously.
- **Weapon Mechanics:** Ballistic raycasting, particle bullet impacts, reload cycle, and ammo tracking.
- **Safe Fallback Audio:** Procedural sound synthesis with dynamic pitch variation and asset audio fallbacks.
- **Score System:** Tracks zombie kills in real time.

---

## 🕹️ Controls

| Key | Action |
|-----|--------|
| **W, A, S, D** | Move |
| **Space** | Jump |
| **Mouse Look** | Aim |
| **Left Click** | Shoot |
| **R** | Reload / Restart on Game Over |
| **ESC** | Quit |

---

## 🚀 How to Run

```bash
# 1. Install Ursina
pip install ursina

# 2. Run the game
python main.py
```
