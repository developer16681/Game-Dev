# Zombie Survival: Nightfall Outpost 🧟

A feature-packed 3D first-person survival shooter built with the **Ursina Engine**.

Defend an enclosed nocturnal military outpost from escalating zombie hordes. Switch weapons, aim for critical headshots, detonate explosive barrels, and collect supply drops to survive wave after wave.

---

## 🎮 Features
- **3 Arsenal Weapons**:
  - `Assault Rifle`: Reliable mid-range automatic rifle with 30-round magazine.
  - `Tactical Shotgun`: High-impact close-range weapon firing 6 buckshot pellets with wide spread.
  - `Rapid SMG`: High cyclic fire-rate spray weapon with 45-round magazine.
- **Zombie Archetypes**:
  - `Walkers`: Standard balanced infected with moderate health and speed.
  - `Runners`: Agile, fast-sprinting infected that flank quickly.
  - `Brutes`: Massive armored tanks with 160 HP that deal crushing 30-damage hits.
- **Precision Headshots**: Dedicated head hitbox dealing **2.5x critical damage** accompanied by a critical sound cue.
- **Wave Progression System**: Dynamic wave director scaling enemy counts and introducing elite types as rounds advance, with wave clear resupply rewards.
- **Tactical Explosive Barrels**: Red fuel barrels that detonate into fiery particle explosions when shot, destroying swarming zombies.
- **Supply Drops**: Defeated enemies randomly drop Health Kits (+35 HP) and Ammo Packs (+25 reserves).
- **Immersive Atmosphere & Audio**: Nocturnal fog, outpost perimeter lighting, camera bobbing, screen damage flash, and 15 custom procedural sound effects + tension BGM.

## 🕹️ Controls

| Key | Action |
|-----|--------|
| **W, A, S, D** | Move |
| **Shift** | Sprint |
| **Space** | Jump |
| **Mouse Look** | Aim |
| **Left Click / Hold** | Fire (Automatic for Rifle / SMG) |
| **1 / 2 / 3** or **Scroll Wheel / Q / E** | Switch Weapons (Rifle / Shotgun / SMG) |
| **R** | Reload / Restart on Game Over |
| **ESC** | Quit |
