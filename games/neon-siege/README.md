# Neon Siege 🔫

A 3D first-person wave-survival arena shooter built with the **Ursina Engine**.

Survive increasingly difficult waves of neon enemies in an atmospheric arena equipped with volumetric lighting, fog, and particle feedback.

---

## 🎮 Features
- **Wave-Based Progression:** Adaptive spawn rates and enemy scaling.
- **Multiple Enemy Types:** Grunts, speedy Runners, and resilient Tanks.
- **Pure Procedural Aesthetics:** Built with geometric primitives, neon accents, and shaders—no bulky assets required.
- **Responsive Weaponry:** Automatic assault rifle with muzzle flashes, recoil, and reload animations.

---

## 🕹️ Controls

| Key | Action |
|-----|--------|
| **W, A, S, D** | Move |
| **Shift** | Sprint |
| **Space** | Jump |
| **Mouse Look** | Aim / Look |
| **Left Click** | Shoot (Hold for auto-fire) |
| **R** | Reload Magazine |
| **ESC** | Quit to Desktop |

---

## 🚀 How to Run

```bash
# 1. Install Ursina
pip install ursina

# 2. Run the game
python main.py
```
