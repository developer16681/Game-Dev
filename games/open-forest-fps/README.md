# Open Forest FPS 🌲

A 3D massive open-world exploration and weapons sandbox built with the **Ursina Engine**.

Explore a huge 300x300 forested arena, gather coins, switch between multiple firearms, and test weapon ballistics and recoil mechanics.

---

## 🎮 Features
- **Large Open Terrain:** 300x300 grassy landscape with procedural trees and obstacle structures.
- **Multiple Weapons:**
  - **Plasma Pistol:** High-tech sidearm
  - **Double-Barrel Shotgun:** Heavy close-range punch
  - **Tactical SMG:** Rapid burst fire
- **Audio & Audio Synthesis:** Custom synthesized SFX for weapons, coin pickups, and ambient exploration BGM.

---

## 🕹️ Controls

| Key | Action |
|-----|--------|
| **W, A, S, D** | Move |
| **Shift** | Sprint |
| **Space** | Jump |
| **Mouse Look** | Look / Aim |
| **Left Click** | Fire Weapon |
| **1, 2, 3** / **Q, E** | Switch Weapons |
| **R** | Reload |
| **ESC** | Quit |

---

## 🚀 How to Run

```bash
# 1. Install Ursina
pip install ursina

# 2. Run the game
python main.py
```
