# Pac-Man Arcade 🕹️

A complete, arcade-accurate Pac-Man style game built with **Pygame**.

Features neon vector aesthetics, classic maze navigation, ghost AI personalities (Blinky, Pinky, Inky, Clyde), power pellets, and procedural retro sound effects.

---

## 🎮 Features
- **Authentic Ghost Personalities:** Chasing, ambushing, and scatter behaviors.
- **Neon Glow Renderer:** Polished glow lines, particle munch effects, and animated sprite mouths.
- **Built-in Audio Generator:** Full procedural sound effects with optional external sound overrides.

---

## 🕹️ Controls

| Key | Action |
|-----|--------|
| **Arrow Keys** / **W, A, S, D** | Steer Pac-Man |
| **Space** / **Enter** | Start Game / Dismiss Menu |
| **P** | Pause / Resume |
| **M** | Mute / Unmute Audio |
| **ESC** | Quit |

---

## 🚀 How to Run

```bash
# 1. Install Pygame
pip install pygame

# 2. Run the game
python main.py
```
