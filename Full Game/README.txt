Drop your own audio here. Supported: .ogg  .wav  .mp3

  bgm            looping background music
  lane_switch    whoosh on lane change
  jump           jump
  slide          slide
  land           landing thud
  crash          obstacle collision
  game_over      game-over jingle
  start          run start

Example: assets/audio/jump.wav
Missing files are replaced by generated sounds in assets/audio/_generated/ (safe to delete).
